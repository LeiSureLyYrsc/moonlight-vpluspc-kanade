# Kanade 实验客户端：Windows x64 双机验收补充

本页适用于 `rem-2-validation`，不是验收结果。普通 LAN、手动添加环回地址和从 **在线设备** 启动是三条不同的路径；前两条成功不能证明第三条可用。主验收单在工作区 `Kanade/docs/m2a-windows-acceptance.md`。

1. 选两台获准使用的测试机；记录两端角色、版本、Actions run、`kanade-validation.json` 中的源码与制品 SHA-256，以及两端侧车的版本。只在隔离的测试配置上做证书变更，不需要替换现役托盘或重启 Foundation。
2. **LAN 对照**：开启 Moonlight 的麦克风偏好，手动添加主机的实际 LAN 地址，确认原生 PIN、画面、音频和输入。保留同一主机的历史 LAN 地址。记下偏好值，不要为了让下一步通过而关闭麦克风。
3. **托管路径**：以 GUI 参数 `--kanade-lab-config` 指向已核对身份与侧车哈希的实验配置，从“在线设备”选择已授权主机。确认数据路径就绪后再配对或选应用。首轮使用 H.264、SDR、默认包长（1392）；显式 1024 是独立的拒绝用例。确认游戏音频与输入正常，但麦克风没有被请求、UDP 48001 没有加入映射。
4. **跨续租观察**：从起流持续到至少两次服务端确认续租，记录相对时刻、映射和媒体是否持续工作。撤销测试授权后记录停止时刻和实际目的地址；旧操作不得改连历史 LAN 地址。另做已建会话失去续租、到期停止的场景，不将到期和主动撤销混记。测试记录不含 PIN、令牌、私钥或原始请求内容。
5. **回到 LAN**：同一 Foundation 进程上显式发起普通 LAN 连接，确认原麦克风偏好、音视频和输入未退化。证书再连、端口冲突、MTU、撤销后旁路及 A/B/A 的完整检查仍按主验收单记录。本页不覆盖公网、ICE 或 TURN。
